# 훌쩍 루트 짜기 기준 (v111, 2026-11-19)
프로 여행러 지인 피드백("직접은 경비만 나와 불편, 블록으로 루트 짜고 자동 평가, 루트만/비용만/둘 다 복사") 반영 첫 버전.

## 들어가는 곳
- '직접' 화면 경비 합계 아래 "이 경비로 루트 짜기" → 전체 화면(닫기 고정, 뒤로가기로 닫힘)
- 받은 링크(?r=)로 들어오면 같은 루트가 바로 열림

## 블록
| 종류 | 자료 | 위치(거리 계산) |
|---|---|---|
| 명소 | 지역 안내 대표 관광지 | 관광공사 좌표 있는 곳만 |
| 밥집 | 착한가격업소 (이름 찾기) | 없음 |
| 숙소 | 착한가격 숙소 | 없음 |
| 체험 | 체험·액티비티 조사표 → 경비 체험 칸과 연동 | 없음 |
| 직접 입력 | 40자 | 없음 |
- 날짜 탭, 위/아래 버튼, 다른 날로 옮기기, PC는 끌어다 놓기 (휴대폰은 끌기 대신 버튼: 손가락이 가리고 잘못 놓이기 쉬움)
- "추천으로 채우기" = 쉽게 모드 추천 일정 생성기 재사용. 기기에 자동 저장(도착지·박수별)

## 루트 점검 (자동)
- 순서: 위치 있는 블록을 가까운 순으로 바꿨을 때 2km 이상·20% 이상 줄면 "약 ○km 줄어요" + 자동 정렬(야경은 맨 뒤)
- 하루 이동 80km 넘음, 블록 9개 이상, 빈 날, 블록 3개 이상인데 식사 없음, 야경 명소가 끝에서 3번째보다 앞, 그날 중심에서 25km 넘게 떨어진 곳, 지역 휴무 메모(예: 경복궁 화요일)
- 거리 = 직선 × 1.2, 시간 = 차 40km/h(대중교통 25km/h), 1.5km 미만은 걸어서 4km/h → 화면에 "추정" 표시

## 공유
- 루트만 / 비용만 / 루트+비용 복사, 끝에 루트 여는 링크
- 링크: ?from&to&nights&people&r= (블록 코드 s=명소 m=밥집 h=숙소 a=체험 c=직접 입력(base64url), '.' 블록, '~' 날짜)

## 한계
- 위치는 관광공사 좌표가 있는 명소만(88개 지역). 밥집·숙소는 위치가 없어 거리 점검에서 빠짐
- 영업시간·실시간 교통 없음. 일본어·중국어 화면은 루트 짜기 글자가 영어로 나옴
