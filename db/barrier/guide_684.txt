서비스개요
개방 데이터 소개
한국관광공사는 국가정보자원의 개방 및 공유 정책에 부흥하여 아래와 같은 OpenAPI 서비스를 
제공합니다.
- 국문 및 다국어(영문, 일문, 중문간체, 중문번체, 독문, 불문, 서문, 노문) 서비스 (9종)
- 국문 무장애 여행 정보 서비스
- 생태관광정보 서비스
- 관광사진갤러리 서비스
- 고캠핑정보 서비스

- 관광 빅데이터 정보 서비스

관광정보 표출 방법
제공되는 각 API를 활용하여 관광정보 목록 및 상세정보 화면을 기획/개발하는 흐름을 설명합니다.
전체적인 관광정보 서비스 기획 및 개발 흐름의 이해를 돕고자 Guide 사이트를 운영하고 있습니다.
추가적인 정보를 원하시면 아래 사이트를 방문하시기 바랍니다.
※ 개방 데이터 활용 사이트: https://data.go.kr/
지역기반 관광정보 서비스
아래 그림은 지역기반의 관광정보 목록을 서비스 하기 위해 API 활용 및 파라미터 전달하는 방법을표현합니다.
[선택]적인 API 조회를 통해 다양하게 조합하여 목록을 표현할 수 있습니다.
※파라미터의 조합에 따라 아래와 같이 표현이 가능합니다.
- 지역별 관광정보: 지역정보(필수) &gt; 타입정보(선택) &gt; 분류정보(선택) &gt; 관광정보목록
- 타입별 관광정보: 타입정보(필수) &gt; 지역정보(선택) &gt; 분류정보(선택) &gt; 관광정보 목록
- 분류별 관광정보: 타입정보(필수) &gt; 분류정보(선택) &gt;지역정보(선택) &gt; 관광정보 목록
- 통합(키워드) 검색: 지역정보(선택) &gt; 타입정보(선택) &gt;분류정보(선택) &gt; 검색된 정보 목록
- 내 주변 관광정보: 타입정보(선택) &gt; 관광정보 목록
- 날짜별 행사축〮제: 지역정보(선택) &gt; 행사공〮연축〮제 목록
- 숙박 검색: 지역정보(선택) &gt; 각 숙박정보 목록
상세정보 화면
인증키 활용 및 API 호출 방법
- 개발계정은 일 1,000건의 트래픽을 제공합니다.
- 개발계정은 자동승인으로 활용신청 후, 약 10분 이후에 사용이 가능합니다. (공공데이터포털 연동)
REST방식의 URL 요청 예시
응답표준은 XML이며, JSON을 요청할 경우 “&amp;_type=json”을 추가하여 요청합니다.
- Json 요청:
https://apis.data.go.kr/B551011/KorWithService2/areaCode2?ServiceKey=ServiceKey&amp;numOfRows=10&amp;pageNo=1&amp;MobileOS=ETC&amp;MobileApp=TestApp&amp;_type=json
서비스키(인증키) 인코딩 방법
- 2015년 1월 이전에 공공데이터포털에서 받은 인증키 경우,
String myKey = “발급받은인증키”;
String ServiceKey= URLEncoder.encode(myKey, "UTF-8");
(한국관광공사 OpenAPI의 모든 Character Set은 UTF-8 설정)
- 2015년 1월 이후에 공공데이터포털에서 받은 인증키 경우, 인코딩 불필요
요청 파라미터에 서비스명 기재
MobileApp 파라미터는 서비스(웹, 앱 등)별로 활용 통계를 산출하기 위한 항목입니다.
URL 요청 시 반드시 기재 부탁드립니다.
https://apis.data.go.kr/B551011/KorWithService2/areaCode2?ServiceKey=ServiceKey&amp;numOfRows=10&amp;pageNo=1&amp;MobileOS=AND&amp;MobileApp=appName
