# 훌쩍 전략 검토: "GPT한테 물어보면 되지 않나?" (2026-11-19)
지인(울고있는 니니즈) 질문: 왜 필요한가 / 개인 여행 온톨로지가 낫지 않나(입력이 귀찮음) / 사업 규모·기업가치·투자 / 특허급 기술 또는 AI가 못 대체하는 아날로그 감성

## 결론
- 지적의 70%는 맞음. 경비 계산·일정 짜기 '기능'은 대체 가능. 이미 하나투어(AI 일정), 마이리얼트립(AI 항공권 탐색 럭키글라이드), 놀유니버스(AI 노리) 등 대기업이 하는 중 (MTN 2026-06-19, 바이라인 2025-12-22)
- 기능으로는 못 이김. 남는 길은 '해자(남이 못 따라오는 것)' 3개뿐

## GPT·대기업이 못 가진 것 (강한 순)
1. 실제 사용자 경비 데이터: 누가 어디서 실제로 얼마 썼는지. 공개 자료에 없음 → 가장 강한 해자. 단, 사람이 모여야 생김
2. 지자체 관계(아날로그): 반값여행·인구감소지역 홍보 담당과의 연결. AI가 대신 못 함
3. 퍼지는 구조: 루트 공유 링크(v111), 카톡 공유 → 받은 사람이 훌쩍으로 들어옴
- 약한 것(정직하게): 공공데이터 묶음(반값 상태·착한가격·버스 실요금)은 누구나 모을 수 있음. 지금은 우위지만 오래 못 감

## 친구의 '개인 여행 온톨로지' 아이디어
- 방향은 맞음 = "내 여행 기록장 → 내 취향 맞춤 추천". 문제는 입력 귀찮음
- 귀찮음 줄이는 방법
  - 후기 쓰기 = 기록 자동 저장 (이미 경비·지역·기분 저장 구조 있음)
  - 휴대폰 사진의 촬영 날짜·위치를 '기기 안에서만' 읽어 지난 여행을 자동 복원 (사진·위치를 서버로 안 보냄). 서버로 보내면 위치정보법·개인정보 검토 필요
  - 안 되는 것: 카드 결제 내역 자동 수집 → 마이데이터 사업 허가 필요
- 이 기록이 쌓이면 1번 해자(실제 경비 데이터)와 같은 것이 됨

## 규모·투자
- 지금 현실: 본업 재직, 겸업 미확인, 수익 0, 사용자 거의 0 → 투자 어렵다는 말 맞음
- 다만 관광 분야는 정부 지원 통로가 있음
  - 관광벤처사업 공모(문체부·관광공사): 2026년 예비 20곳·초기 40곳·성장 40곳, 최대 1억 원 사업화 자금, 2026년 접수 2/3~3/4 (헤럴드경제 2026-02-02). 재직자 자격은 공고(투어라즈)로 확인 필요
  - 관광기업 데이터·AI 활용 지원(관광공사): 웹·앱 보유 '중소기업' 대상, 컨설팅 + 광고비 최대 1천만 원 (뉴시스 2026-05-04) → 사업자등록 뒤
- 목표 시점: 2027년 2월 예비관광벤처 지원. 그때까지 필요한 것: 사업자등록·겸업 정리, 실사용 지표(방문자·인증 후기 수), 지자체 1곳 협의 기록

## AI를 적이 아니라 손님으로
- AI 검색이 훌쩍 데이터를 인용하게: 검색 페이지(구간별 경비)에 출처·기준일 구조화 → AI 답변의 출처로 노출
- 나중에: AI가 부르는 도구(경비 계산 API) 제공 → "AI가 대체 못 하는 기술"이 아니라 "AI가 쓰는 데이터 공급원"

## 우선순위 다시 정하기
1. 실제 경비 데이터 쌓기: 지인 → 반값여행 다녀온 사람 → 리워드
2. 지자체(B2G): 지자체 누리집에 넣는 "우리 지역 경비 계산기" 위젯 + "방문객 실제 경비 리포트"
3. AI 검색 인용용 데이터 페이지
- 멈출 것: 새 기능 추가 (지금 기능으로 충분)
