# 훌쩍 쉽게 모드(옛 시니어 모드)·환율 표시 기준 (2026-11-13 반영, v34~v49 / 환율 기준 2026-11-17 v58 / 이름 변경 2026-11-19 v106)

## 1. 화면 모드
- v106 (테스터 의견 "주니어는 어렵고, 주니어·시니어로 나누는 것도 싫다, 시니어는 나이 든 느낌" 반영)
  - 이름: `주니어 | 시니어` → `쉽게 | 직접` (영 Easy/Custom, 일 かんたん/自分で, 중 简单/自选). 쉽게가 왼쪽(먼저)
  - 처음 온 사람은 '쉽게' 화면부터. 전에 고른 모드가 있으면 그대로, 경비 링크(?from=..&to=..)로 들어오면 '직접'
  - 쉽게 화면 맨 아래 "직접 다 보면서 고를래요" 버튼 → 직접 화면으로
  - 코드 안 이름(junior/senior, hz-ui 저장값)은 그대로 둠 → 기존 방문자 선택 유지
  - 테스터가 말한 "이지/셀렉"은 쉬운 우리말 원칙에 따라 "쉽게/직접"으로 바꿈. 원하면 글자만 바꾸면 됨
- 첫 화면 검색창 위에 큰 버튼 "큰 글씨로 쉽게 계산하기 · 요원이 아홉 가지만 묻고 다 계산해 드려요"(v34 일곱 → v37 여덟 → v39 아홉)
- 직접(옛 주니어) = 검색창 + 요원 추천 + 탑승권 내역(지도는 "지도에서 고르기" 창). 쉽게(옛 시니어) = 훌쩍요원이 한 번에 하나씩 묻는 화면. 계산 값은 같다.
- 아래 2~8의 "시니어"는 지금의 "쉽게 모드"를 뜻함
