- 자료

  - 부산광역시 메뉴 외국어 표기사전 API(MenuLangService, 827개 = 800선 + 부산 27개)

  - 한식이 아닌 흔한 메뉴(커피류·우동·돈가스·탕수육·짬뽕·치킨 등 약 30개)만 훌쩍 자체 표기
