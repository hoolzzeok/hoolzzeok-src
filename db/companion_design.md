# 훌쩍 동행 찾기 설계안 (2026-11-19, 미구현)

## 출발점
- 테스터 의견: "가까운 지역에 동행 구하기 기능이 있으면 좋겠다" / 대표: 위치기반 도입하면서 동행 고민 중
- 훌쩍만의 차별점: 동행하면 1인 경비가 실제로 얼마나 줄어드는지 보여줌 (v103 인원 계산 재사용)
  - 예: 서울→강릉 1박 자차, 혼자 207,000원 → 둘이 129,000원 → 넷이 107,000원

## 1. 위치: GPS 안 씀
- "가까운 지역" = 사용자가 고른 출발 시·군 (이미 있는 출발지 값) + 시·군 사이 거리
- 이유: 기기 위치(GPS·와이파이·기지국)를 모아 서비스하면 위치기반서비스사업 신고 대상, 미신고 시 3년 이하 징역 또는 3천만 원 이하 벌금 (catchsecu 2024, 이현 법률 블로그 2026-01)
- 사용자가 직접 고른 지역은 개인위치정보가 아니라는 해석(catchsecu, 주소는 개인정보) → 신고 부담 없음. 단, 출처 1곳 해석이라 GPS 도입 전 방송미디어통신위원회 확인
- 나중에 "내 위치로 찾기"를 넣으면: 기기에서 시·군 이름만 고르게 하고 좌표는 서버로 안 보냄, 그래도 도입 전 신고 여부 확인

## 2. 흐름
1. 경비 결과 화면에 "이 일정으로 동행 찾기" 버튼
2. 글 자동 채움: 출발 시·군, 도착지, 날짜(±며칠 가능), 박수, 이동수단, 1인 경비
   - 자동 문구: "같이 가면 1인 약 ○원 → ○원" (차 나눠 타기·2인 1실 계산)
3. 직접 고르는 것: 모집 인원(1~3명), 여행 스타일(알뜰·보통·여유), 원하는 동행(성별 무관/같은 성별), 연령대(20대·30대…)
4. 찾기 목록: 같은 도착지 + 날짜 겹침 + 출발지 가까운 순. 카드에 "○○ 출발, 같이 가면 1인 ○원 절약"
5. 연락: 신청 → 글쓴이 수락 → 그때만 서로 연락 수단 공개 (처음엔 오픈채팅 링크, 나중에 사이트 쪽지)

## 3. 안전 (가장 중요)
- 로그인 필수, 만 19세 이상만 (1단계 자기 확인 → 2단계 휴대폰 본인인증, 건당 비용 확인 필요)
- 실명·사진 비공개, 닉네임만. 성별·연령대는 본인이 공개 여부 선택
- 정확한 출발 동네·숙소 위치는 글에 못 쓰게 (시·군까지만)
- 신고·차단, 신고 3번 쌓이면 자동 숨김 후 관리자 확인
- 안전 수칙 고정 표시: 첫 만남은 사람 많은 곳, 일정·동행 정보 가족에게 공유, 돈 먼저 보내지 않기, 숙소 같은 방 강요 거절
- 금지: 돈 받는 가이드·투어 판매 글(여행업 무등록 문제), 만남·이성 목적 글, 미성년 의심 글
- 글은 여행 날짜 지나면 자동 마감·삭제

## 4. 법 체크
- 위치정보법: GPS 안 쓰면 신고 피함 (위 1번)
- 개인정보: 성별·연령대·연락 링크를 새로 받으면 처리방침에 항목·보관 기간 추가
- 여행업: 동행끼리 비용 나누기는 개인 간 일. 훌쩍이 일정을 짜서 돈 받고 모객하면 여행업 등록 대상 → 하지 않음
- 정보통신망법: 신고 처리 절차·연락처(help@hoolzzeok.com) 게시

## 5. 만드는 순서와 조건
- 지금 만들면 안 되는 이유: 글이 없으면 빈 게시판 → 신뢰 하락. 동행은 사람이 있어야 의미 있음
- 시작 조건(둘 중 하나): 월 방문 3,000명 이상, 또는 승인된 후기 50개 이상
- 1단계(가볍게): 로그인 + 동행 글 + 오픈채팅 링크 + 신고. 기존 Supabase(후기 표) 구조 재사용
- 2단계: 사이트 쪽지, 휴대폰 본인인증 배지, 날짜 알림
- 3단계: 지역·축제별 "동행 모임" (지자체 협업)

## 6. 수익 아이디어
- 동행 성사 → 2인실·렌터카·투어 제휴 링크 (광고 표시)
- 본인인증 배지 유료(소액) 또는 인증 비용 회수
- 지자체: "혼자 온 여행자 동행 이벤트" 홍보비 (반값여행 지역과 궁합 좋음 — 2인 이상 환급 한도 20만 원)
- 축제 기간 "같이 갈 사람" 모음 페이지 → 축제 홍보 자리

## 7. 4060 취미 동행 방향 (2026-11-19 추가)
- 판단: 수요는 맞음(자녀 양육 끝난 4060의 취미·여행 동행). 다만 "이성 만남"으로 알리면 안 됨
- 이유
  - 만남·채팅 서비스는 본인인증·대화 저장·신고 기능이 없으면 청소년유해매체(19금) 대상, 성인인증 없이 운영 시 3년 이하 징역 또는 3천만 원 이하 벌금 (여성가족부 2020-12 시행, 뉴시스)
  - 중장년 대상 사기가 많음: 2026년 1분기 투자사기 피해의 75.2%가 50대 이상 (헤럴드경제 2026-09-16) → 동행 서비스가 사기 통로가 되면 사업 자체가 끝남
  - 브랜드: "여행 경비 계산" 신뢰가 핵심 자산. 만남 앱 이미지가 붙으면 지자체 협업이 어려워짐
- 방향: "같은 취미·같은 또래 여행 동행"
  - 글 종류: 걷기·둘레길, 사진, 맛집, 축제, 온천, 등산(가벼운), 낚시
  - 연령대 필터(40대·50대·60대 이상)와 "같은 성별만" 옵션
  - 처음엔 2~4명 소규모만. 큰 모임(10명 이상)은 산악회 같은 단체 → 비용 걷기·일정 대행이 생기면 여행업 문제
- 사기 막는 장치
  - 사이트 밖 연락처는 만나기로 한 뒤에만, 돈 이야기·투자·코인·대출 단어 자동 경고
  - "동행이 돈을 빌려 달라 하면 사기" 고정 안내
  - 본인인증 배지는 2단계에서 필수로 검토
- 수익: 취미별 제휴(사진 출사지 숙소, 온천 할인권, 둘레길 패키지), 지자체 "5060 동행 여행 주간" 홍보비
