# 훌쩍 후기 리워드 기준 v2 (2026-11-19, 미구현)
기존 '훌쩍_콘텐츠_리워드_설계.md'(루트 채택·주간 순위·지역 챌린지)를 지금 만든 '딸깍 후기'(v95~v98)에 맞춰 1단계 기준으로 정리. 순위·챌린지는 기존 문서 그대로.

## 목적
- 보상은 "글"이 아니라 "실제 경비 데이터"에 준다. 데이터 신뢰도 1순위 약점(계산값과 실제 비교 0건)을 푸는 장치
- 좋았는지·아쉬웠는지와 상관없이 같은 보상 (긍정 후기에만 주면 기만 소지 + 데이터 왜곡)

## 등급
| 등급 | 조건 | 보상 |
|---|---|---|
| 일반 후기 | 승인된 후기 | 돈 없음. "후기 작성자" 표시만 |
| 경비 인증 후기 | ① 실제 금액 4항목 이상(교통·숙박·식비·현지교통·체험·기념품) ② 증빙 사진 1장 이상(예매 내역·영수증, 이름·카드번호·전화번호 가림) ③ 다녀온 지 60일 이내 | 기프티콘 3,000원 |
| 경비 완전 인증 | 6항목 모두 + 증빙 2장 이상 | 기프티콘 5,000원 |
- 부가 보상(돈 아님): "경비 인증" 배지, 계산기 화면에 "실제 다녀온 사람 경비" 칸으로 노출(작성자 닉네임)

## 상한
- 1인 월 2건, 같은 구간(출발-도착)은 같은 달 1건
- 전체 월 예산 10만 원(약 20~30건), 예산 다 쓰면 다음 달로 (화면에 남은 수 표시)

## 표시 (공정위 추천·보증 심사지침)
- 보상받은 후기는 맨 위(첫 줄)에 자동 표시: "훌쩍에서 기프티콘 3,000원을 받고 쓴 후기예요. 좋고 나쁨과 상관없이 같은 금액을 드려요."
- 한국어로, 맨 위에. 영어(AD)만 쓰거나 아래·더보기에 숨기면 안 됨 (2024-12 개정 기준, 법률신문 2026-11-05)
- '우수 후기'로 뽑아 주는 상(조건부 대가)도 경제적 이해관계 → 표시 필요
- 작성자가 자기 SNS에 옮길 때도 "훌쩍 리워드 받음" 표시 안내

## 지급
- 승인 후 7일 안에 기프티콘(시판품 구매해 전송). 받을 휴대폰 번호는 발송 후 바로 파기
- 자체 포인트를 현금처럼 쓰게 하지 않음(선불전자지급수단 규제 소지)
- 세금: 건당 소액이라 기타소득 원천징수 없음(기존 문서 근거). 최종 세무사 확인

## 증빙 사진 처리
- 확인용으로만 받고 공개 안 함. 확인 끝나면 30일 안에 삭제, "확인됨" 표시와 금액만 남김
- 개인정보 처리방침에 항목 추가: 증빙 사진(확인 후 30일 내 파기), 기프티콘 수령 번호(발송 후 파기)
- 사진 속 다른 사람 개인정보가 보이면 반려

## 부정 방지
- 1인 1계정(2단계부터 휴대폰 본인인증), 같은 영수증·사진 재사용 차단(사진 지문 비교)
- 인터넷에서 가져온 사진, 날짜 안 맞는 영수증 → 반려 + 지급분 회수 + 이용 정지 (약관 명시)
- 관리자 승인 전에는 지급 안 함

## 시작 조건 (순서)
1. 로그인·후기 공개 (보호책임자 이름·시행일, 카카오 웹훅, 겸업 확인)
2. 사업자등록 (보상은 사업 비용 → 등록 후 지급이 깔끔)
3. 증빙 사진 올리기 기능 (Supabase Storage, 비공개 버킷)
4. 약관·처리방침 갱신 후 시작. 처음 2주는 월 예산 5만 원으로 시험

## 수익 연결
- 경비 인증 데이터 → 계산기 정확도 표시("실제 후기 ○건과 평균 ○% 차이") → 지자체·제휴사 제안 근거
- 지역 챌린지로 넘어가면 보상금은 후원 지자체·업체가 부담

## 오픈 활성화 계획 (2026-11-19 추가)
### 0단계: 씨앗 (돈 0원, 공개 전 2주)
- 대표 본인 여행 5건 + 지인 단톡방 10명에게 지난 여행 경비 입력 부탁(보상 없음) → 첫 화면이 비어 보이지 않게 최소 15건
- 지인 글도 실제 다녀온 것만. 가짜 후기는 절대 금지

### 1단계: 오픈 이벤트 4주 "내 여행, 실제로 얼마 썼나요?"
- 기간 한정 완화: 2026년 안에 다녀온 여행이면 인정(60일 제한 이벤트 기간만 해제)
- 선착순: 경비 인증 첫 100건 5,000원 (최대 50만 원)
- 추첨: 인증 후기 1건 = 응모 1회, 주마다 3명 3만 원 기프티콘 (4주 36만 원)
  - 경품 1건 5만 원 이하로 → 원천징수·주민번호 수집 피함
  - 응모 조건·발표일·당첨 연락 방법·개인정보 파기를 이벤트 화면에 공개
- 총 예산 상한 86만 원. 사업자등록 뒤, 제휴 수익 또는 사업 계좌에서만

### 핵심 타깃: 반값여행 다녀온 사람
- 반값여행은 환급받으려고 영수증·결제 내역을 이미 모아 둠 → 경비 인증이 가장 쉬운 사람들
- 화면: 반값여행 안내 페이지에 "다녀오셨어요? 실제 경비 남기고 기프티콘 받기"
- 데이터 가치: "반값 지역 실제 경비 + 환급 후 부담" → 지자체 제안 자료로 바로 씀

### 퍼지게 하는 장치
- 후기 승인되면 "예상 ○원 vs 실제 ○원" 비교 카드 자동 생성 → 카톡·인스타 공유 (공유 글에 훌쩍 주소)
- 공유만으로는 보상 안 줌(공유 보상은 공유 글에도 광고 표시가 필요해져 복잡)
- 친구 초대 보상은 하지 않음: 가짜 계정 유인이 큼

### 측정 (이벤트 끝나고 판단)
- 인증 후기 수, 1건당 비용, 후기 본 사람의 계산기 사용률, 공유 카드 클릭 수
- 1건당 비용 7,000원 넘으면 추첨 줄이고 선착순만

## 외국인 리워드
- 기프티콘은 한국 휴대폰 번호·카카오톡이 있어야 받기 쉬움 → 외국인은 돈 보상 기본 없음
- 대신(돈 아님):
  - 영어·일본어·중국어 후기 그대로 공개 + "Real cost from a traveler" 배지
  - 국적별·도시별 "외국인이 실제 쓴 경비" 칸에 소개(닉네임)
- 한국 번호·카카오톡이 있는 외국인(유학생·장기체류)은 한국인과 같은 기프티콘 기준
- 해외 거주자에게 돈·상품권을 줄 경우 비거주자 세금·송금 방식이 달라짐 → 세무사 확인 전에는 하지 않음
- 증빙: 외국 카드·여권 정보 가림 안내(영·일·중 문구)
- 데이터 가치: 외국인 실제 경비는 지자체 외국인 유치 담당에게 팔 수 있는 자료(DataLab엔 없는 1인 경비)
- 나중 단계: 외국인 대상 투어·패스 제휴사(클룩 등)와 "후기 쓰면 제휴사 할인 코드" — 할인 비용을 제휴사가 부담하는 구조로 협의
